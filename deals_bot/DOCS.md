# Deals Bot

בוט טלגרם פרטי שמפרסם מוצרי עליאקספרס עם קישורי שותפים: בערוץ טלגרם, בקבוצות וואטסאפ ובדף פייסבוק.

## איך עובדים איתו

1. בטלגרם, בצ'אט הפרטי עם הבוט, שולחים קישור שותפים מ-Portals ותמונה של המוצר או צילום מסך של דף המוצר. אפשר להוסיף כמה מילים משלך, למשל "עובד עם Matter".
2. הבוט כותב פוסט בעברית ושולח תצוגה מקדימה עם כפתורים:
   - **📢 פרסם בכל מקום**, או רק בטלגרם, רק בוואטסאפ או רק בפייסבוק
   - **🔄 גרסה אחרת**, **✂️ קצר יותר**
   - **❌ בטל**
3. לתיקון ידני: עונים (Reply) על התצוגה המקדימה עם הטקסט המתוקן.

כשה-API של עליאקספרס מאושר וממלאים את שלושת שדות ה-AliExpress, מספיק לשלוח קישור: הבוט מביא לבד את השם, המחיר והתמונה.

## הגדרה ראשונה

1. **telegram_bot_token**: הטוקן מ-BotFather.
2. שומרים, מפעילים את התוסף ושולחים לבוט הודעה. הוא יענה עם ה-ID שלך.
3. **telegram_admin_ids**: מוסיפים את ה-ID, שומרים ומפעילים מחדש.
4. **telegram_channel**: שם הערוץ, למשל `@my_channel`. הבוט צריך להיות מנהל בערוץ עם הרשאת ניהול הודעות.
5. **anthropic_api_key**: מפתח מ-console.anthropic.com.

## וואטסאפ

השתמש במספר נפרד, לא במספר האישי. זה לא API רשמי של וואטסאפ, ווואטסאפ עלול לחסום מספר שנראה לו אוטומטי.

1. המספר הנפרד צריך להיות חבר בקבוצות, ובקבוצה שרק מנהלים כותבים בה, גם מנהל.
2. שלח לבוט `/whatsapp` וסרוק את ה-QR מהטלפון של המספר הנפרד: וואטסאפ ← הגדרות ← מכשירים מקושרים ← קישור מכשיר.
   אפשר גם `/whatsapp 9725XXXXXXXX` כדי לקבל קוד חיבור במקום QR.
3. שלח `/groups` וסמן את הקבוצות לפרסום.

## פייסבוק

אפשר לפרסם אוטומטית רק בדף (Page). לקבוצות פייסבוק אין API מאז 2024, אז אחרי הפרסום בדף משתפים את הפוסט לקבוצות בלחיצה.

ממלאים **facebook_page_id** ו-**facebook_page_token** (טוקן דף עם הרשאת `pages_manage_posts`).

## פקודות

- `/status`: מצב כל החיבורים
- `/whatsapp`: חיבור וואטסאפ
- `/groups`: בחירת קבוצות וואטסאפ
- `/logout_whatsapp`: ניתוק וואטסאפ
- `/help`: הסבר

## גיבוי

ההתחברות לוואטסאפ והקבוצות שנבחרו נשמרות בתיקיית הנתונים של התוסף, ונכללות בגיבוי של Home Assistant.
